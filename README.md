# My Hyprland Config

## What you will find

/hyprland.lua -> Main Config file
/config/ -> Subfolder of different configs (for cleaner structure)
    /config/animations.lua -> config for all animation related settings
    /config/autostart.lua -> all autostart applications are defined here
    /config/binds.lua -> all keybinds are set here
    /config/colors.lua -> color theme definitions
    /config/decorations.lua -> basic decoration settings
    /config/environment.lua -> main environment settings
    /config/inputs.lua -> touchpad configuration (laptop)
    /config/misc.lua -> miscellanious settings
    /config/monitors.lua -> monitor settings (layout, resolution, refreshrate etc.)
    /config/variables.lua -> definitions for config wide variables
    /config/windowrules.lua -> rules for window behaviour (floating/tiling etc.)
    /config/workspaces.lua -> workspace settigns
